# Website xin lỗi người yêu

## Cách mở bằng VS Code

1. Giải nén thư mục `xin-loi-em`.
2. Mở thư mục bằng Visual Studio Code.
3. Mở `index.html` bằng trình duyệt. Để nhạc hoạt động ổn định, nên cài tiện ích **Live Server**, sau đó bấm chuột phải vào `index.html` → **Open with Live Server**.

## Chỉnh nội dung

- Sửa bức thư: `content/buc-thu.js`
- Đổi chữ ký, đường dẫn ảnh hoặc tên nhạc: `js/config.js`
- Đổi ảnh chủ đạo: chép ảnh mới vào `assets/images/`, rồi sửa `heroImage` trong `js/config.js`
- Đổi hai ảnh kỷ niệm: thay `memory-01.jpg` và `memory-02.jpg`
- Thêm nhạc: chép bài hát MP3 vào `assets/music/` và đổi tên thành `our-song.mp3`

Mẹo: không đổi tên các thư mục `assets`, `css`, `js`, `content` nếu chưa quen sửa đường dẫn.
